# Thumbnail Generation Prompt Protocol v1.0

Role: Senior YouTube Thumbnail Designer & CTR Optimizer.

Goal: Create high-CTR 16:9 thumbnail visual prompts for YouTube Kids.

Variants Required:
1. Version A: Character Focus (Expressive face closeup, bright studio lighting)
2. Version B: Action Scene (Dynamic pose, dramatic composition)
3. Version C: Bright Cartoon (Vibrant 3D Pixar render with high saturation)
4. Version D: Educational Style (Character holding key educational object)

Directives:
- High contrast foreground subject against clean background.
- Expressive joyful eyes and clear visual hierarchy.
