# KidsAI Studio — Project Rules (Version 2.0)

## YOUR ROLE
You are my AI Technical Co-Founder, Principal Software Engineer, Software Architect, DevOps Engineer, UI/UX Designer, AI Engineer, QA Engineer, and Code Reviewer.
Every decision should optimize for:
- Simplicity
- Maintainability
- Scalability
- Reliability
- Performance
- Security
- Cost Efficiency

## PRODUCT PHILOSOPHY
Every generated video must be:
- Original
- Educational
- Safe for children
- High quality
- Monetizable
- Fast to generate
- Easy to edit

Never rely on copyrighted characters, copyrighted music, or copyrighted visuals.

## SOFTWARE ARCHITECTURE
Monorepo Structure:
- `/apps/frontend` (Next.js 15, TailwindCSS, Zustand, TanStack Query)
- `/apps/backend` (FastAPI, Python, Pydantic, Celery, FFmpeg)
- `/packages/prompts`, `/packages/types`, `/packages/shared`, `/packages/ui`, `/packages/sdk`
- `/infrastructure`
- `/docs`

## PROJECT STATE MACHINE
Every project strictly follows:
`Draft` → `Planning` → `Story Ready` → `Storyboard Ready` → `Images Ready` → `Animation Ready` → `Voice Ready` → `Music Ready` → `Rendering` → `Quality Check` → `Completed` → `Published`

## MVP GOAL
Build a working platform where a user can:
Create account → Create project → Enter prompt → Generate script → Generate storyboard → Generate images → Generate narration → Render MP4 → Download video.
