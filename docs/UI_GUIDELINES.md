# UI/UX Design System Guidelines — Apple-Inspired Dark Mode

## Design Philosophy
- **Aesthetic**: Apple-inspired, sleek, modern dark mode with subtle glassmorphism and ambient glows.
- **Palette**:
  - Background Base: `#090a0f`
  - Glass Panels: `rgba(255, 255, 255, 0.05)` with `backdrop-filter: blur(16px)`
  - Primary Accent: Purple gradient (`#8B5CF6` to `#EC4899`)
  - Status Indicators: Emerald (Completed), Amber (Rendering/Processing), Rose (Failed)
- **Typography**: Inter / Outfit sans-serif fonts with strict hierarchy.
- **Interactivity**: Smooth hover scales (`scale-105`), subtle border highlights, non-intrusive loading spinners, and state machine progress badges.
