# Prompt Library — KidsAI Studio v2.0

- **Rules**: Pacing rules by age group (3-5 gentle/slow, 6-8 energetic), clean markdown tags, add cadence pauses.

- **Role**: Executive Director Master Protocol.
- **Rules**: Enforce project state machine sequence.
